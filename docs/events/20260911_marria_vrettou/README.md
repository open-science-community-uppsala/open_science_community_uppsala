## Talk description

Within Open Science, data should be 'As open as possible, as closed as needed'.
Data about humans is essential for research in the life science,
yet it is sensitive data too, hence there are rules and regulations
to deal with it responsibly.

In this talk, Maria Vrettou will talk about open human data:
what are the implications of working with sensitive data,
what does 'Open Data' really mean in this context.
